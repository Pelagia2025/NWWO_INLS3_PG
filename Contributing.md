# Zasady współpracy

Dziękuję za zainteresowanie moim projektem. Aby ułatwić współpracę, proszę o przestrzeganie poniższych zasad.

## 1. Przygtowanie projektu

1. Sklonuj repozytorium na swój komputer
``` bash
git clone https://github.com/Pelagia2025/NWWO_INLS3_PG.git
```

2. Przejdź do katalogu projektu
``` bash
cd REPO
```
3. Utwórz wirtualne środkowisko
```bash
python -m venv .venv
```

4. Aktywuj środkowisko i zainstaluj zależności, jeśli projekt zawiera plik *requirements.txt*

## 2. Praca z gałęziami
- **nie wprowadzaj** zmian bezpośrednio na gałęzi main
- do każdego zadania utwórz osobną gałęź
- feature/add-task - nowa funkcjonalność
- docs/update-readme - zmiany w dokumentacji

## 3. Zasady pisania kodu

- Nadawaj zmiennym i funkcjom zrozumiałe, opisowe nazwy w języku angielskim.
- Pisz małe, wyspecjalizowane funkcje spełniające jedną odpowiedzialność
- Kod ma być czytelny dla zespołu – jeśli potrzebujesz napisać skomplikowaną linijkę, dodaj krótki komentarz wyjaśniający intencję.
- nie powielaj kodu (zasada DRY)
- **przed wysłaniem zmian sprawdź czy program działa poprawnie**

## 4. Commity
-Każdy commit powinien zawierać krótki i zrozumiały opis zmian w trybie rozkazującym. 
Przykłady:
```bash
git commit -m"feat: dodaj zadanie.."
git commit -m"fix: popraw element input"
git commit -m"docs: zaktualizuj readme.md"
```
