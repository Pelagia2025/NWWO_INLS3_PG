## Wymagania systemowe
Do uruchomienia jest **wymagane**:
- python w wersji 3.12 lub nowszy
- git
- terminal
- edytor kodu np: visual studio code

Sprawdzenie wersji Pythona:
```

bash
python --version
```

Sprawdzenie wersji Gita:
```

bash
git --version
```



## Urochumianie projektu
Aby urochomić należy skopiować repozytorium i ospalić główny plik:
```
bash
python main.py
```
